# 常见问题

## 总结是从摘要开始的吗？为什么只读一部分？

以前的「前 8,000 字符」取的是 PDF 文字的开头，通常是标题、作者、摘要、关键词和引言开头——**不是**只读摘要，但也确实**读不到方法与结论正文**。所以从 v0.10.0 起有两个按钮：

- **生成总结**（默认，快、便宜）：读论文的**开头与结尾**约 8,000 字。开头给摘要与问题背景，结尾给结论与结果，覆盖一篇论文最关键的两端；提示里会明确告诉模型「中间正文未提供」，它可以自己按偏移补读，并在「依据」里说明读了哪些部分。
- **总结全文（分段精读）**：把整篇正文按约 7,000 字切段（超长文档在全文范围内均匀取样，始终包含开头和最后一节，最多 14 段），逐段压缩成要点后再合并成总结。会覆盖方法与结果，但请求次数多，费用与耗时都更高。

总结下方会写明本次依据（「开头与结尾节选」或「全文分段精读（N 段）」），换一种方式重新生成会覆盖原来的总结。扫描件仍需先 OCR，否则两种方式都没有文字可读。

## 为什么还有输出长度上限？能去掉吗？

单次回复的输出上限是**模型本身**的硬性限制（deepseek-chat / deepseek-reasoner 一次最多 8192 个输出 token），不是应用加的限制，把它写大一点会被接口直接拒绝，所以无法真正去掉。应用能做的两件事都已经做了：

1. `max_tokens` 直接设为模型允许的最大值 8192。它只是「上限」而不是「目标」——只有真正生成的 token 才计费，写长回答不会因此多花钱。
2. **撞到上限不再报错丢弃**。以前一碰到上限就提示「回复达到 Token 上限」并把整段回答扔掉；现在会自动从中断处接着写（最多续写 3 次，接近 3 万 token），你看到的是连贯的一篇回答。若仍未写完，回答末尾会提示「回复「继续」即可接着写」，那才是需要你补一句的情况。

另外两条限制也保留着，因为模型的上下文窗口是有限的，超出会让整次请求失败：单轮读取资料总量约 15 万字符、单轮最多 16 轮只读查询。它们只在让 AI 自己反复翻文献时才可能碰到，提示文字已经改成「把问题拆小一点」的动作建议。

## 聊乱了怎么办？会不会把之前的内容带进去？

点「学术对话」顶部的**新建对话**即可，不需要清空历史。每条对话都是独立的：模型只会看到这条对话自己的历史消息，其他对话的内容不会串进来。旧对话仍在顶部的下拉列表里，可以随时切回去继续，也可以单独重命名或删除当前对话（删除一条不影响其他对话与已上传附件）。

## 我同时在跟两个方向，画像要来回改吗？

不需要。「设置 → 学术画像」可以建立多个画像（例如「方向 A · NLP」和「方向 B · 医学影像」），侧边栏随时切换当前画像；**每条对话会记住自己创建时使用的画像**，之后你把当前画像切到另一个方向，这条对话仍用它自己的画像回答。也可以在对话顶栏单独为某条对话指定画像。

点「新建画像」会**立刻**在最前面建好一个空白画像并设为当前画像，再在下方表单里填名称、专业、研究领域等；两个方向背景相似时可以用「复制当前编辑的画像」再改。除名称外的字段都可以留空后补，只有「每周可用小时数」有 1–168 的范围限制。删除画像前会弹出应用内确认框，至少保留一个画像；引用它的对话会自动改用当前画像。

## 对话里可以上传哪些文件？会上传到服务器吗？

可以上传 Word（.docx）、Excel（.xlsx）、PowerPoint（.pptx）、PDF、图片（PNG/JPG/GIF/BMP）以及 .txt、.md、.csv、.json、.html、.tex、.bib、.py、.log 等文本文件，单个不超过 20 MB、一条消息最多 8 个。文件本身只保存在本机数据目录的 `uploads/`，**不会**上传给第三方；应用在本机把文档解析成文字，只有解析出的文字（以及勾选多模态模型时的图片内容）会随消息发送给 DeepSeek。旧版 .doc/.xls/.ppt 需先另存为新格式；扫描件与纯图片没有文字层，需要先自行 OCR。

## 上传了图片，AI 却说看不到，为什么？

当前模型（如 `deepseek-chat`）只接收文字。应用不会假装读过图片：图片保存为本地附件并显示在对话里，同时明确告诉模型“看不到图像内容”。需要图片理解时，请在「设置 → AI 连接」勾选「当前模型支持图片输入（多模态）」，并使用支持图片的模型；勾选后图片会以标准图片内容发送。

## 上传的文档很长，AI 只读了一部分吗？

超过 6,000 字的文档，消息里只带开头部分，并提示模型可用只读工具 `read_workspace`（`attachment` 动作）按字符偏移继续读取全文，单次 8,000 字。可以让 AI「继续读取」或指定章节；只看到开头时不要当作全文。

## 可以直接下载知网、万方的所有论文吗？

不能。应用的综合检索接入 arXiv、Crossref 和 Europe PMC 的公开索引；中文与英文元数据的覆盖量和完整程度因来源而异。知网、万方提供官方入口，订阅全文仍需你自己的机构或个人权限。取得 PDF 后可导入；应用不绕过付费、登录或验证码。

## 为什么有的论文显示“前往获取全文”？

索引有记录不代表存在开放 PDF。只有来源返回了可用 PDF 且下载域名已支持时才提供直下；登录页、失效链接和超大文件会给出错误提示。可以在来源网页下载后导入。

## 自动翻译和分类不准确怎么办？

在详情的「引用与文献索引」中修正中文题目、分类及检索标签。也可重新翻译分类。没有 Key 时原文照常可读；AI 生成结果应核对，引用始终使用原文标题。语言初始按题目是否含中文判断，可手动调整。

## 引用可以直接作为学位论文的最终参考文献吗？

自动生成国标顺序编码制条目，并按文献自身类型标记（期刊 [J]、学位论文 [D]、会议 [C]、图书 [M]、预印本 [PP/OL]、网络文献 [EB/OL]）。打开详情就会自动识别，外文作者写成 `EINSTEIN A`，四位以上作者省略为 `et al.`。PDF 与开放来源都没有提供的要素（如学位授予单位）会按国标省略，并在条目下方说明省略了什么，不会写成占位符。引用编号默认 [1]，应按论文的实际引用顺序调整；学校模板细则仍需自行核对。

## 为什么知网一键就有完整引用，这里有时缺卷期或授予单位？

知网拥有出版单位提交的结构化记录，本地 PDF 未必印着这些信息。应用会依次查 PDF 正文、DOI、Crossref / OpenAlex / Europe PMC / arXiv / DataCite，找到精确标题匹配才写入；仍然查不到就按国标省略该要素，而不是编造或用占位符。需要时可在「补全 / 修改资料」中补上，之后生成的引用会优先使用你填写的值。

## 为什么删除本地 PDF 后列表会消失，但恢复文件还能重新出现？

「我的文献」只显示文件实际存在的记录，自动刷新或手动刷新会更新列表。内部元数据暂存，避免外接盘离线造成永久丢失；需要彻底移除元数据可在文件可见时使用详情里的删除选项。

## 如何获取 API Key？

在 DeepSeek 开放平台账户中创建 API Key，复制到设置页。不要把 Key 发给他人、粘贴到对话框或提交到代码仓库。

## 应该选择哪个模型？

应用按需求默认使用 `deepseek-chat`，也可填写服务商当前支持的模型 ID。模型可用性以账户及服务商实际返回为准。自定义名称仍使用 DeepSeek API；本版本不提供任意第三方接口地址配置。

## 会产生费用吗？

应用不提供模型额度。AI 对话、计划生成、总结、翻译和测试连接会使用你账户的额度；实际费用以服务商控制台为准。软件本身不代收 API 费用。

## Key 无效或连接超时怎么办？

检查 Key 是否正确、账户余额和模型权限。网络超时可稍后重试；凭据管理器错误需确认系统账户已解锁。Key 不会回显，留空保存只修改模型。

## 为什么扫描论文无法总结？

当前版本从 PDF 文本层提取内容，不包含 OCR。扫描件需先识别文字；加密或损坏文件需提供可读取版本。

## 为什么 AI 回复不完整？

网络中断或 Token 上限会显示错误。本轮未完成对话不会写入历史。请缩短输入或拆分任务；资料过多时请指定计划或论文名称，让 AI 分次读取。总结按钮默认提供前 8,000 字符，不能据此认为 AI 已审读全文。

## DeepSeek 能直接生成软件里的学习计划吗？

可以。在学术对话中要求生成完整计划，回复下方会出现「采纳学习计划」。点击后保存到计划库，可编辑和导出；重复点击不会重复创建同一条计划。「学习计划」页也会发现尚未采纳的对话计划。旧版普通文字计划通过规则识别，可能漏识别；可请 AI 重新整理为完整学习计划。

## AI 能看到我的全部文献和计划吗？

每次 AI 请求都会读取最新资料。已有计划、文献元数据、摘要和总结会作为上下文提供；超出单次容量的内容以及本地 PDF 文字可由模型分次查询。它不能修改或删除资料，也不会自动采纳计划。所有资料可供查询不代表每次回复都已阅读所有 PDF；模型仍受上下文容量限制，扫描件需先 OCR。

## PDF 导出和 Markdown 预览为何不同？

PDF 使用纯 Python 排版，支持中文、标题、段落及基本粗体。复杂表格、公式、代码高亮和远程图片不保证与 Markdown 预览一致。需要完整 Markdown 结构时选择 .md 导出。

## 文件已存在时为什么不能下载？

为防止覆盖已有论文，下载会拒绝同名文件。可在文献详情删除本地副本后重新下载，或改用另一目录。如果下载成功但数据库保存失败，请检查该目录中的 PDF 后再重试。

## 为什么文件还在 C 盘？

新版关联导入不会复制 PDF，原文件在哪个盘就从哪里读取；打开阅读、翻译都只按需读取，不会写出第二份论文。旧版导入的副本仍留在应用数据目录，可在文献库点「检查重复副本」，确认它们与你原有文件逐字节相同后一次性清理，并改为关联原文件。

数据库和默认下载目录的位置都可以自己指定：**设置 → 存储位置**可以更改数据目录（会把数据库和旧版副本一起迁移到新文件夹）和默认 PDF 下载目录，两个面板都会在你仍位于系统盘时提醒。默认下载目录取自系统的「下载」文件夹（如果系统已把下载重定向到别的盘，这里就跟着走），再往下建一个 `ScholarMate` 子文件夹；留空下载目录时保存到这里。文献库的「本地存储」面板会一直显示这两个路径和实际占用。

如果指定的盘符当前没有挂载（例如移动硬盘没插），应用会临时回到默认目录，插上后重新启动即可继续使用原来的数据。

## 文件名只有数字能分类吗？

可以使用可提取的 PDF 正文：先识别首页信息及关键词，再由已配置的 AI 从正文提取原标题、作者、年份、刊物、分类和标签；写回之前会逐字核对是否真的出现在 PDF 里，对不上就丢弃，所以不会因为文件名是编号而凭空生成标题。扫描件、加密或损坏文件会提示识别失败，不能保证从任何文件自动恢复完整书目信息。

## 为什么知网有完整引用，个别本地 PDF 却无法生成？

知网拥有出版单位提供的结构化作者、期刊、日期与页码。单个 PDF 可能缺少这些信息。本版会自动读取文内信息并按精确来源匹配补充；没有可靠依据时停止生成，避免给出错误引用。

# ScholarMate v0.10.0

ScholarMate 是一款桌面学术学习助手，将 AI 对话、学习计划、论文检索、PDF 阅读、论文总结、翻译和 GB/T 7714-2015 引用整理集中在一个应用里。

## 主要功能

- 建立个人学术画像，让 AI 回答结合专业、研究方向和学习目标。
- 管理多条独立对话，并上传 PDF、Word、Excel、PowerPoint、文本和图片作为资料。
- 根据目标与每周时间生成学习计划，跟踪任务并导出计划。
- 搜索 arXiv、下载或导入论文，在本地建立可检索的文献库。
- 阅读 PDF，生成论文速览或全文分段总结。
- 按页生成左右对照译文，不修改原 PDF。
- 自动整理 GB/T 7714-2015 参考文献。
- 对话、计划和文献记录保存在本机，API Key 使用系统凭据库保存。

# ScholarMate v0.10.0

（2026-09-15）

- **总结不再只看开头**：原来的「前 8,000 字符」取的是 PDF 文本的前 8,000 字——通常是标题、作者、摘要和引言开头，**不包含方法与结论正文**，因此长论文的「主要结论」经常是模型猜的。现在「生成总结」改为读取论文的**开头与结尾**（约 6,000 + 2,000 字，含摘要与结论），并在系统提示里说明「只提供了开头与结尾」，如需补读可自行按偏移读取全文。
- **新增「总结全文（分段精读）」**：把整篇正文按约 7,000 字切段（长文档在全文范围内均匀取样，**始终包含开头与最后一节**，最多 14 段），逐段压缩成带「背景／方法／结果／结论」标签的要点，再合并成最终的结构化总结。费用与耗时高于速览，由用户自己点。
- 总结会记录依据：界面显示「本次总结依据：开头与结尾节选（含摘要与结论）」或「全文分段精读（N 段）」，数据库新增 `summary_scope` 与 `summary_characters`，重新打开文献仍能看到上次用的是哪种方式。
- 摘要/引言的抓取按段落或句末断句，不会从半句中间切断；`POST /paper/summarize` 新增 `scope=excerpt|full` 参数（默认 `excerpt`，向后兼容）。

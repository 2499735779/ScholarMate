## 自动化

运行 `python -m pytest src-tauri/python/tests -q` 和 `npm test`。全部测试使用临时数据库、模拟 keyring 或模拟网络，不读写个人 API Key。

在受限文件系统（例如 Windows 沙箱内）运行 pytest 时，如遇到 `pytest-of-<user>` 目录权限错误，请显式指定基线目录：`python -m pytest src-tauri/python/tests -q --basetemp=.pytmp\bt`。

覆盖：本机令牌鉴权、Key 不回传/不入库、画像持久化和校验、四类任务画像注入、流式完成/中断、历史事务保存、服务商错误与重试、计划 CRUD 与导出、arXiv 搜索解析、下载重定向限制/无效 PDF、提取损坏/扫描/加密 PDF、总结节选截断。

## v0.4.0 新增验收

- 关联原 PDF 后无新论文副本；鉴权读取字节与原文件一致；移除记录后原文件保留。

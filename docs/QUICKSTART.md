# 快速入门

ScholarMate 是本地优先的学术助手，帮助你制定计划、管理 arXiv 文献和开展个性化学术对话。

## v0.10.0 论文总结的两种方式

文献详情里的「论文总结」现在有两个按钮：

- **生成总结**（默认）：读论文的**开头与结尾**各一部分（约 6,000 + 2,000 字），开头拿摘要与背景，结尾拿结论与结果——这是替代旧版「只读前 8,000 字」的关键改动，以前结论常常读不到。速度快、费用低，适合先快速了解一篇论文。
- **总结全文（分段精读）**：把整篇正文按约 7,000 字切段（长论文在全文范围内均匀取样，**总是包含开头和最后一节**，最多 14 段），逐段先压缩成带「背景／方法／结果／结论」标签的要点，再合并成结构化总结。覆盖方法与结果，适合精读或写综述，但请求次数多、费用与耗时更高。

总结下方会标明本次依据（「开头与结尾节选（含摘要与结论）」或「全文分段精读（N 段）」）。想让 AI 直接接着读全文，也可以在「学术对话」里问，它可以用只读工具按偏移读取本地 PDF。

## v0.9.0 长回答会自动续写

模型的单次回复有输出上限（deepseek-chat 一次最多 8192 token），这是模型本身的限制，无法取消。应用的处理方式：

- `max_tokens` 直接取模型允许的**最大值** 8192（只是上限，不会因为设大而多花钱）；
- 撞到上限时**自动从中断处接着写**，最多续写 3 次（接近 3 万 token），你看到的是连贯的一篇回答；
- 如果续写 3 次后仍未结束，回答末尾会提示「回复「继续」即可接着写」，你可以直接回一句「继续」；
- 只有让 AI 自己反复翻文献时才可能碰到另外两条保护性限制（单轮约 15 万字符资料、16 轮只读查询），提示会建议把问题拆小。

## v0.8.0 多会话与多画像

**多个对话，互不干扰。**「学术对话」顶部是一条对话栏：

1. **新建对话**：聊乱了、换话题了，点一下就开一条全新的，不用清空历史。新对话从零开始，不会把上一段对话的内容带给模型。
2. **切换对话**：用下拉列表在历史对话之间来回切换，列表里显示每条对话的标题和消息数；标题默认取第一条消息，点铅笔图标可以改名。
3. **删除对话**：只删当前这一条，其他对话和已上传的附件都保留。导出也只导出当前这条。

**多个画像，两个方向同时开工。**侧边栏底部有「当前画像」下拉框，随时切换；「设置 → 学术画像」里可以：

- **新建画像**：点一下立即在最前面建好一个空白画像并设为当前画像（默认名「画像 N」），再在下方表单里填写名称、专业、研究领域、目标与每周可用时间。除名称外的字段可以留空后补，只有每周小时数限制在 1–168。
- **复制当前编辑的画像**：两个方向背景相似时，先复制再改，不用重复录入。
- **设为当前画像**：计划生成、总结、翻译等任务使用当前画像。
- **删除画像**：会弹出应用内确认框；至少保留一个，删除后原本使用它的对话会自动改为使用当前画像，不会失效。

**对话会记住自己用的画像。**新建对话时默认使用当前画像，之后你在侧边栏切到另一个方向，这条对话仍然用它自己的画像继续回答——所以可以让「供水管网」和「医学影像」两条对话同时进行。也可以在对话顶栏的「这条对话使用的画像」里单独给某条对话换画像。

升级旧版本无需操作：原来的单一画像会变成第一个画像（名称取自研究领域），原来那条长长的对话记录会归入「历史对话」。

## v0.7.0 对话上传文件

在「学术对话」里，除了打字，还可以把自己的资料一起交给 AI：

1. 点输入框左下角的「上传文件」，或直接把文件**拖进输入框**，也可以**粘贴剪贴板里的截图**。一条消息最多 8 个附件，单个不超过 20 MB。
2. 支持格式：**Word（.docx）、Excel（.xlsx）、PowerPoint（.pptx）、PDF、图片（PNG/JPG/GIF/BMP）**，以及 .txt、.md、.csv、.json、.xml、.yaml、.html、.tex、.bib、.py、.js、.r、.sql、.log 等文本文件。旧版 .doc/.xls/.ppt 请先在 Office 里另存为新格式。
3. 文档在**本机**解析成文字后随消息交给 AI（原文件不会上传到任何第三方）；超过 6,000 字的文档先发送开头，AI 需要时可用只读工具读取全文。Excel 按工作表逐行输出、PPT 按幻灯片输出，表格数字不会丢。
4. 图片分两种情况：设置页勾选「当前模型支持图片输入（多模态）」后，图片作为图片内容发送；未勾选时图片仍保存在本机、在对话里可预览，但 AI 看不到图中内容——界面会提前提醒，不会让它假装读过。
5. 附件保存在数据目录的 `uploads/` 下，随数据目录一起迁移；对话历史能看到每条消息上传了什么，导出对话会带出附件名。点附件上的 × 只是从待发送列表移除，已上传文件可用接口 `DELETE /chat/attachment?id=...` 删除。

注意：扫描件和纯图片 PDF 没有文字层，需要先自行 OCR；旧版 Office 二进制格式无法直接读取。

## v0.3.0 新功能

- **本周学习首页**：查看执行中计划的当前周、任务清单和完成进度，点击任务即可标记完成。
- **计划执行安排**：采纳当周自动作为第 1 周，以本地日历周一为边界。计划详情可暂停/恢复、调整第 1 周日期、手动补充任务。暂停期间经过的周不计入进度；修改起始日期可从中间周开始。
- **拒绝和删除**：对话里的计划可采纳或拒绝；拒绝后仍可恢复为候选。已采纳计划可在详情删除，删除后不会再次出现在待采纳列表。
- **双语文献库**：我的文献以卡片呈现中英文标题，按语言、分类筛选。搜索覆盖原题、译名、作者、标签、摘要、总结和 DOI，可输入多个关键词。分类和翻译由已配置的 AI 自动生成并缓存，可在详情修正或重试。
- **更多文献来源**：「发现文献」支持 arXiv、Crossref、Europe PMC 综合检索，也提供知网、万方、国家哲学社会科学文献中心的官方入口。只有支持的开放 PDF 来源可直接下载；其他论文请访问出版页面取得文件，再使用「导入本地 PDF」。导入将保存一份应用管理的副本，单个文件最大 28 MB。
- **国标引用**：详情点击「生成引用」获得顺序编码制参考文献。按文献实际类型生成期刊、学位论文、会议、图书或在线文献条目，保留原标题。缺少出版信息时显示待补项，请通过「补全 / 修改资料」修正后再用于定稿；编号应按你的论文顺序调整。
- **自动刷新**：首页和文献页每 30 秒及返回窗口时刷新，另有手动刷新按钮。文件不存在时自动从「我的文献」隐藏；仅保留内部资料以免外接盘暂时断开造成误删。文件恢复到原路径后会重新显示。完全删除记录请使用详情删除功能。

旧计划会保留原始起始周（以创建日期计算）。明确包含“## 第 1 周”和列表任务的正文会自动拆分为周任务；无法识别的旧计划不会随意分配到某周，可在详情补充任务或重新整理正文。跨周范围内的任务会安排到该范围的每一周。

1. 打开「设置」，填写自己的 DeepSeek API Key，默认模型为 `deepseek-chat`。点击「测试连接」，成功后保存配置。
2. 填写专业、学历、研究领域、兴趣、目标和每周可用时间，保存画像。
3. 打开「学术对话」，点击自我介绍示例，检查回复是否正确反映你的研究背景。
4. 在对话中要求生成完整学习计划，回复完成后点击「采纳学习计划」即可保存。「学习计划」页也会显示对话中识别出的待采纳计划；详情可返回来源对话。也可直接新建计划，生成后编辑、保存并导出 Markdown 或 PDF。
5. 在「文献管理 → 探索 arXiv」搜索英文关键词。选择论文后下载，可在下载前输入自定义目录。
6. 从「我的文献」打开详情，生成总结、翻译摘要，或提取 PDF 文本并选取片段翻译。

## 本地数据与隐私

- API Key 存在 Windows Credential Manager 或 macOS Keychain；前端只能看到是否已配置。
- 画像、计划、对话和论文元数据存于你自己选择的数据目录中的 SQLite 数据库；默认是系统应用数据目录，可在「设置 → 存储位置」改到任意盘符，更改时会连数据库一起迁移。
- PDF 默认保存在默认下载目录下：系统「下载」文件夹（若系统已重定向到其他盘则跟随）中的 `ScholarMate` 子目录，可在「设置 → 存储位置」或下载前的目录输入框中更改。导入本地 PDF 只关联原文件，不复制。
- 数据目录和下载目录的位置记录在操作系统配置目录的 `storage.json` 中，只有几行路径，不包含任何文献内容。
- AI 请求会将画像、本次输入、已保存计划和文献资料上下文发送给 DeepSeek。资料较多时，模型可按需只读查询计划全文、文献摘要与总结，以及本地 PDF 提取出的文字。PDF 原文件不会上传；文字内容可能发送给模型。总结按钮默认使用前 8,000 字符，但模型可根据任务继续查询资料。
- 对话草稿自动保存在本机，切换页面或重启后恢复。发送失败或中断时会恢复原消息；发送期间新写的草稿优先保留。
- 采纳后的计划独立保存，并保留生成它的回复快照；清空对话不会删除已采纳计划及其来源快照。
- 离线可管理本地数据；AI、连接测试、arXiv 搜索和下载需要联网。
- 自动标题翻译和分类会把该文献的标题、摘要节选与画像发送给 DeepSeek，并消耗账户额度；已完成的整理不重复调用。失败后可在详情重试。
- 主题切换与帮助入口位于侧边栏底部。

## 导出与备份

桌面版导出时会出现系统保存窗口。请先保存计划，再导出。删除操作无法撤销；删除文献时可选择保留元数据与总结。备份请退出应用后复制整个应用数据文件夹及 PDF 目录，API Key 需要在新设备重新填写。

## v0.4.0 阅读与内容索引

- “我的文献 → 关联本地 PDF（不复制）”直接使用你选中的原文件。文件名是编号、下载序号时，会优先从 PDF 首页、正文和关键词段识别信息；自动分类会读取前几页内容，使用设置中的 AI。
- 打开“阅读 / 引用”就能看到 PDF。摘要及文件位置收起在详情中。上下页切换与缩放适用于两侧页面。
- 英文页面点击“翻译当前页 · 中英对照”，左侧原文、右侧中文覆盖显示。每页单独触发，译文仅在当前会话内存中保存，不生成另一份 PDF。复杂表格、公式、旋转文字以原文为准；较长译文可在文字块内滚动查看。
- “自动识别并生成引用”从 PDF 与精确匹配的出版来源整理国标顺序编码制引用。期刊使用 [J]，学位论文使用 [D]，不会将所有 PDF 当成网络文献。v0.5.0 起改为打开详情即自动识别，无法确认的字段按国标省略并说明，不再需要用户替换占位符。
- 旧版导入副本：可用文献库的「检查重复副本」批量清理，也可在详情展开“摘要与文件位置”单独关联原文件。只有文件内容完全一致、旧副本位于应用旧导入目录且没有其他记录使用时才清理。不会扫描或批量删除你的其他文件。
- 关联的原文件在移除文献记录时保留；若在系统中移动/删除，应用会隐藏该记录。应用自身下载、管理的文件仍按删除确认框处理。
- 扫描 PDF 没有可提取文字时需要先 OCR；本版不含 OCR 引擎。
- 沉浸式翻译官方服务在阅读区的折叠入口中，打开后由你自行选择文件。内置对照功能使用你配置的 AI，并未安装第三方浏览器插件。

## v0.5.0 阅读、引用与磁盘占用

- **打开即读、左右对照**：打开“阅读 / 引用”立即显示整篇 PDF，可连续滚动、翻页、缩放。英文文献点击“翻译全文 · 中英对照”后逐页翻译：左侧原文，右侧同一页把中文覆盖在原来的文字位置，图表、公式和原 PDF 文件都不改变。翻译过程可随时停止，已翻译的页面不会重复请求；中文文献会自动识别并提示无需翻译。译文只保存在当前阅读会话，关闭后不落地。
- **引用自动完成**：详情页打开后自动生成 GB/T 7714-2015 顺序编码制条目，不需要点击或替换占位符。来源顺序是 PDF 首页与页脚、DOI 精确查询，再到 Crossref、OpenAlex、Europe PMC、arXiv、DataCite 的精确标题匹配。外文作者按国标写成 `EINSTEIN A` 形式，四位以上作者省略为 `et al.`。条目下方会说明依据和已省略的要素；如果确实需要补，可以点“补全 / 修改资料”，你填写的字段优先。
- **文件名不重要了**：文件名为 `12345`、`download (2)`、`cnki_2026` 时，会读 PDF 正文识别真正的原标题、作者、年份和刊物；模型给出的内容必须在正文中逐字出现才会写入，识别不到就保留原文件名。
- **磁盘占用看得见、位置可以自己定**：文献库新增“本地存储”面板，显示应用数据目录、默认 PDF 下载目录、关联原文件数量和实际副本字节数；“检查重复副本”按字节比对，列出应用旧导入目录里与你自己文件完全相同的副本，确认后清理并改为关联原文件。清理只作用于应用自己创建的副本，不会动你的其他文件。
- **存储位置可改到其他盘**：「设置 → 存储位置」可以分别更改数据目录与默认下载目录。数据目录更改时会把数据库和旧版副本一起复制到新文件夹，校验通过后才删除原文件，历史记录里的路径也会同步更新；默认下载目录取自系统「下载」文件夹（跟随系统重定向），因此通常不再落在系统盘。两个位置都在系统盘时面板会给出提示。

## v0.6.0 存储位置

打开「设置 → 存储位置」，可以看到当前数据目录（数据库与旧版导入副本）和默认 PDF 下载目录，两者都能改到任意盘符：

1. 点「更改数据目录」→ 选择目标盘上的**空文件夹**（例如 `E:\ScholarMate-data`）。应用会把数据库和旧版副本复制过去，逐文件校验大小后才删除原目录中的文件，文献记录里的路径同步更新，随后照常使用。
2. 点「更改默认下载目录」→ 选择目标文件夹（例如 `E:\papers`）。之后在「发现文献」下载时留空目录就用这里。
3. 想回到默认位置，点对应的「恢复默认位置」即可，同样会迁移数据。

默认下载目录是系统「下载」文件夹下的 `ScholarMate` 子目录；如果 Windows 已把下载重定向到其他盘，默认就跟着在那个盘。位置记录保存在系统配置目录的 `storage.json`，只含路径；桌面启动器与后端共用同一份记录，重启后依然生效。指定的盘符暂时不可用（移动硬盘未插）时，应用会回到默认目录运行，不会把数据写乱或删除。

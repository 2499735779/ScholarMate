# ScholarMate

ScholarMate 是一款面向学生、研究人员和知识工作者的桌面学习助手。它把 AI 对话、学习规划、论文检索、文献阅读、总结、翻译和引用整理集中在一个应用里，帮助你从“找到资料”一路完成到“读懂并使用资料”。

## 它可以做什么

### 和 AI 讨论学习与研究问题

- 建立个人学术画像，让回答结合你的专业、研究方向和学习目标。
- 创建多条独立对话，不同课题之间互不干扰。
- 上传 PDF、Word、Excel、PowerPoint、文本和图片作为对话资料。
- 长回答可自动续写，适合论文分析、方案设计和系统性解释。

### 制定和管理学习计划

- 根据目标与每周可用时间生成学习计划。
- 查看本周任务、勾选完成进度，并暂停或恢复计划。
- 在应用内修改计划，导出为 Markdown 或 PDF。

### 搜索和管理论文

- 搜索 arXiv 论文并下载到本地文献库。
- 导入本机已有 PDF，不重复复制原文件。
- 按标题、作者和关键词查找收藏的文献。
- 自定义数据库与论文下载目录，方便把资料放在其他磁盘。

### 阅读、总结和翻译论文

- 在应用内连续阅读 PDF。
- 生成包含摘要与结论的论文速览。
- 对全文分段精读，整理背景、方法、结果和结论。
- 按页生成中外文左右对照译文，原 PDF 文件不会被修改。

### 整理规范引用

- 自动提取论文标题、作者、年份、期刊等信息。
- 生成 GB/T 7714-2015 顺序编码制参考文献。
- 对无法确认的信息保留提示，避免用占位内容冒充真实数据。

### 数据保存在本机

- 对话、画像、计划和文献记录存放在你的电脑上。
- API Key 使用系统凭据库保存，不以明文写入数据库。
- 应用仅监听本机地址；云端 AI 请求由本地后端发出。

## 下载与安装

在 [Releases](https://github.com/2499735779/ScholarMate/releases/latest) 页面下载：

- Windows 64 位：`ScholarMate_0.10.0_x64_zh-CN.msi`
- 完整源码：`ScholarMate-source-0.10.0.zip`
- 文件校验：`SHA256SUMS.txt`

安装包目前没有数字签名，Windows 首次安装时可能显示发布者提示。请从本仓库的 Releases 页面下载，并可使用 `SHA256SUMS.txt` 核对文件完整性。

## 开始使用

1. 安装并打开 ScholarMate。
2. 在设置中填写兼容 OpenAI 接口的 API 地址、API Key 和模型名称；默认用途面向 DeepSeek 接口。
3. 建立你的学术画像，包括专业、研究方向、目标与每周学习时间。
4. 从“学术对话”“学习计划”或“发现文献”开始使用。

论文文件、学习记录和 API 使用费用均由用户自行管理。不同模型的上下文长度、图片识别能力和计费方式可能不同，请以所选服务商说明为准。

## 系统要求

- Windows 10/11 64 位
- Microsoft Edge WebView2 Runtime（多数 Windows 10/11 已预装）
- 使用 AI 功能时需要网络连接和可用的模型 API

开发、测试和源码构建说明见 [`docs/`](docs/) 目录。
